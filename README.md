## Noark 5-arkivassistent

**Kildebasert søke- og svarassistent for Noark 5 versjon 6.0 og arkivregelverket fra 2026**

[Prøv arkivassistenten](https://rolfss.github.io/Rolfs-projects-2026/noark-assistent/) · [Kildekode og dokumentasjon](./noark-assistent/)

- 71 kontrollerte kildeposter fra ti offisielle kilder.
- Lokalt, BM25-lignende søk med arkivfaglige synonymer og kravnummergjenkjenning.
- Korte svar med kilde, seksjon, side og kravnummer.
- Kravbibliotek for Noark-krav, metadataelementer og veiledning til arkivforskrifta § 5.
- Virker uten API-nøkkel, server, konto eller opplastning.
- 13 automatiske domenetester.

## Archive Assist

**Metadatahjelp for arkivfiler**

[Prøv Archive Assist](https://rolfss.github.io/Rolfs-projects-2026/archive-assist/) · [Kildekode og dokumentasjon](./archive-assist/)

Archive Assist analyserer filer lokalt, foreslår strukturert metadata, viser mangler og eksporterer dokumenter med manifest og metadata-sidecars.

- Lokal filbehandling uten opplastning eller API-nøkkel.
- SHA-256-kontrollsum og duplikatindikasjon.
- Eksport til JSON, CSV og ZIP.
- Tolv automatiske tester av domenelogikk og ZIP-bygger.
