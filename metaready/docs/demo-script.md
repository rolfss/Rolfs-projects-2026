# Demo script

## 90 seconds

1. **Start on the portfolio view.** Explain that the product connects information governance to practical reuse decisions.
2. **Open the legacy procedure archive.** Show missing owner, provenance, access, retention and the unresolved lineage link.
3. **Apply one demonstrated remediation.** Point out that the asset version changes and an audit event is created.
4. **Open AI readiness.** Select the retrieval-augmented assistant use case and show the evidence, assumptions and blockers.
5. **Create remediation items.** Open the prioritized backlog.
6. **Conclude:** MetaReady turns “our information is messy” into explainable, owned work.

## Five minutes

### 1. Portfolio and catalog

Show the seven asset types, search and filter controls, ownership gaps and asset status. Register a new asset with an intentionally short description and send it through profile validation.

### 2. Quality diagnosis

Open the weak procedure collection. Explain required versus recommended rules. Apply ownership and review-date remediation. Show the updated version and audit trail.

### 3. AI-readiness assessment

Assess the collection for a retrieval-augmented assistant. Walk through accountability, source authority, currency, access, privacy, machine readability, terminology, quality evidence, lifecycle and human oversight. Emphasize that blockers override an attractive average.

### 4. Lineage and impact

Open the service-request dataset or workforce-capacity report. Trace models and code lists upstream and reports or APIs downstream. Use the table alternative and record an impact decision.

### 5. Remediation and export

Create backlog items from the readiness assessment. Explain the visible priority formula. Export the governance brief and show how evidence, limitations and decisions travel with the recommendation.
