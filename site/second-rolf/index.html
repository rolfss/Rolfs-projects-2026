Slik er boten bygget

Ministral 3 14B via Ollama på en Windows-PC med RTX 5070 Ti (16 GB VRAM), Ryzen 7 9800X3D og 32 GB RAM. Nettsiden ligger på GitHub Pages; Cloudflare formidler live-chatten til PC-en.

Oppbygning, modell og maskinvare

Dokumentert oppsett. Grønt statuslys krever at lokal AI og gjeldende profesjonelle kunnskapsbase er bekreftet.

Vanlig chat, tydelige grenser

Generelle emner er tillatt, men private opplysninger om Rolf er ikke med. Ingen tilgang til private meldinger, interne arbeidsdata, passord, filer eller styring av PC-en. Ingen fullmakt til å inngå avtaler. Ingen betalt sky-AI som fallback.

Modellen kan ta feil. Den søker ikke på nettet og kan ikke bekrefte ferske hendelser. Profilsvar er kildebaserte; generelle svar bruker modellens kunnskap.
